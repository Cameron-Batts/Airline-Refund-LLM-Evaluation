Airline Refund Decisions: LLM Prompt Evaluation

Problem
LLM-generated policy decisions can be incorrect despite valid formatting and can follow instructions embedded in untrusted case text.
Approach
Adapted a 13-case synthetic refund-policy experiment comparing minimal, policy and policy-plus-examples prompts, with separate parsing, accuracy and injection checks.
Impact
Historical records showed improvement from 7/13 to 10/13 correct with policy context, while the injection case remained a failure. Built an offline evaluator and documented unverified API provenance.
